Install Mesh Town on a Keenetic router (experimental)

For Keenetic routers with Entware, MIPS and 64-bit ARM.

  • macOS
  • Windows
  • Linux
  • Android
  • OpenWrt
  • Keenetic

1. Install

Note. Experimental. The package has not been tested on a live KeeneticOS router yet.

Entware must be installed on the router. Over SSH:

wget -O- https://mesh-town.github.io/meshtown-keenetic/install.sh | sh

The node runs as the service /opt/etc/init.d/S99meshtown.

2. Join your network

A router node usually joins a network you already have. Ask a member for a single-use invite (Invite a member on their node page), then run this once while the service is stopped:

/opt/etc/init.d/S99meshtown stop
meshtown run --config /opt/etc/meshtown/config.json --invite mesh-invite2-…

The command saves the network to the settings file, so after a restart the service stays in the network without the invite. Stop it with Ctrl+C once it reports joining, then start the service. To share the router's web panel with the network, see the router notes.

Update

opkg update && opkg upgrade meshtown

Troubleshooting

The script stops with exit code 1
Entware is not installed.
The script stops with exit code 2
The router's architecture is not supported.
Where is the settings file?
/opt/etc/meshtown/config.json. Keep it private.
