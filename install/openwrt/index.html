Install Mesh Town on an OpenWrt router

Three steps: the package, your network and the phones and computers behind the router.

OpenWrt 24.10 and 25.12 on 64-bit ARM, 32-bit ARM Cortex and x86_64. MIPS, ARMv5/v6 and 32-bit x86 routers are not covered yet.

  • macOS
  • Windows
  • Linux
  • Android
  • OpenWrt
  • Keenetic

  1. Install

    As root on the router:

    wget -O- https://mesh-town.github.io/meshtown-openwrt/install.sh | sh

    The service starts at boot.

  2. Join your network

    A router node usually joins a network you already have. Ask a member for a single-use invite (Invite a member on their node page), then run this once while the service is stopped:

    /etc/init.d/meshtown stop
meshtown run --config /etc/meshtown/config.json --invite mesh-invite2-…

    Stop it with Ctrl+C once it reports joining, then start the service: the network is now saved in the settings file and survives restarts. To share the router's web panel with the network, see the router notes.

  3. Connect phones and computers

    Phones, tablets and computers on the router's home network open sites through Mesh Town once their Wi‑Fi or network settings point to the router's setup address (PAC). iPhone and iPad work this way too — there is no app for them.

    First open the proxy for the home network: on the router's node page (port 7777) go through the setup steps and click "Open for the home network", or set "socks": {"access": "localnet"} in the settings file and restart the service.

    The setup address is http://<router address>:1080/proxy.pac, for example http://192.168.1.1:1080/proxy.pac. The node page shows the exact one.

    1. iPhone and iPad: "Settings" → "Wi‑Fi" → ⓘ next to the network → "Configure Proxy" → "Automatic", paste the address into "URL", "Save".
    2. Android: Wi‑Fi settings → the network → "Proxy" → "Proxy Auto-Config", paste the address into "PAC URL", "Save".
    3. macOS: "System Settings" → "Network" → the connection → "Details…" → "Proxies" → "Automatic Proxy Configuration".
    4. Windows: "Settings" → "Network & internet" → "Proxy" → "Use setup script" → "Script address".
    5. Linux (GNOME): "Settings" → "Network" → "Proxy" → "Automatic" → "Configuration URL".

    Note. The proxy has no password: any device on the home network can use it, and so can guest Wi‑Fi unless it is separated. Do not open port 1080 on the WAN side.

Update

OpenWrt 24.10

opkg update && opkg upgrade meshtown

OpenWrt 25.12

apk update && apk upgrade meshtown

Troubleshooting

My router has a MIPS chip

MIPS, ARMv5/v6 and 32-bit x86 routers are not covered yet.

Where is the settings file?

/etc/meshtown/config.json. Keep it private.
