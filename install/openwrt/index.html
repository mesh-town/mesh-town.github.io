Install Mesh Town on an OpenWrt router

For OpenWrt 24.10 and 25.12 on 64-bit ARM, 32-bit ARM Cortex and x86_64. MIPS, ARMv5/v6 and 32-bit x86 routers are not covered yet.

  • macOS
  • Windows
  • Linux
  • Android
  • OpenWrt
  • Keenetic

1. Install

As root on the router:

wget -O- https://mesh-town.github.io/meshtown-openwrt/install.sh | sh

The service starts at boot.

2. Join your network

A router node usually joins a network you already have. Ask a member for a single-use invite, then follow the router notes to join and to share the router's web panel with the network.

Router notes · Usage reference

Update

OpenWrt 24.10:

opkg update && opkg upgrade meshtown

OpenWrt 25.12:

apk update && apk upgrade meshtown

Troubleshooting

My router has a MIPS chip
MIPS, ARMv5/v6 and 32-bit x86 routers are not covered yet.
Where is the settings file?
/etc/meshtown/config.json. Keep it private.
