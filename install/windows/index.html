Install Mesh Town on Windows

Three steps: the app, the node page and your network. After that, shared devices open by name.

64-bit Windows on x86.

  • macOS
  • Windows
  • Linux
  • Android
  • OpenWrt
  • Keenetic

  1. Install

    Download meshtown.exe, the tray app. For a terminal or a server there is meshtown-cli.exe.

    Note. The program is not signed, so SmartScreen may warn on the first launch. Choose More info, then Run anyway.

  2. Open the node page

    Start Mesh Town. The node page opens from the tray icon, or from the sign-in link printed at start:

    Mesh Town page: http://127.0.0.1:7777/?token=…

    The link works once and for 10 minutes. On the first visit, set a password; after that, sign in with it.

  3. Create or join a network

    Press Create a new network and name it, for example home-lab. You become its first administrator; add a second one soon.

    To add a device or a person, press Invite a member: you get a single-use string, valid for a day, that does not contain the network key. Hand it over in person. The page also shows it as a link and a QR code; on Android, Scan QR reads it.

    On the new device, press Join with an invite and paste the string, or in a terminal:

    meshtown run --invite mesh-invite2-…

    Until a member is online, the node reports that it is waiting for network members.

Open a device by its name

On the device that runs the service, open the network's Shared services (ports) tab and publish the port, to all members or to selected ones. Only programs running on that device itself can be shared.

Each device has a name, two random words by default, such as finch-unwary; for a short one such as nas, set node.name in the settings file. The Ports shared with you tab shows the exact link for every port.

In the browser: in your system's proxy settings, turn on automatic proxy configuration (PAC) and paste http://127.0.0.1:1080/proxy.pac. Then type the address with http://, for example http://nas.meshtown. Ordinary sites go through the node while Mesh Town runs and open directly while it is stopped; *.meshtown addresses work only through the node.

For SSH, RDP and other programs, press Open on this computer: a member's port gets a local port, for example 22 becomes 127.0.0.1:2022.

Update

Download the file again from the same link; it always points to the latest build.

Troubleshooting

SmartScreen warns

See the note above.

Where are the settings and logs?

%APPDATA%\meshtown\ holds config.json and the logs meshtown.log and meshtown-tray.log. Keep config.json private.

The other devices never appear

One of the networks may prevent direct connections; try another network, such as home Wi-Fi.
