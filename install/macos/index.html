Install Mesh Town on macOS

For Macs with Apple silicon or Intel.

  • macOS
  • Windows
  • Linux
  • Android
  • OpenWrt
  • Keenetic

1. Install

With Homebrew (recommended)

brew install mesh-town/meshtown/meshtown
meshtown

meshtown starts the menu bar app; meshtown-cli runs the node in a terminal. A Homebrew install is not marked as downloaded from the internet, so macOS does not stop the first launch.

As an app

Download for Apple silicon or for Intel, unzip and move MeshTown.app to Applications.

Note. The app is signed ad hoc and is not notarized, so Gatekeeper stops the first launch of a zip downloaded in a browser. Open System Settings → Privacy & Security and press Open Anyway, or run:

xattr -dr com.apple.quarantine /Applications/MeshTown.app

2. Make sure it works

The node page opens from the menu bar icon, or with the sign-in link printed at start:

Mesh Town page: http://127.0.0.1:7777/?token=…

On the first visit, the page asks you to set a password. The sign-in link works once and for 10 minutes; after that, sign in with that password.

3. Create or join a network

On the node page, press Create a new network and give it a name, for example home-lab. You become its first administrator; making a second administrator soon is a good idea.

To add a device or a person, press Invite a member. You get a single-use string, valid for a day, that does not contain the network key. Hand it over in person.

On the new device, press Join with an invite and paste the string. In a terminal:

meshtown run --invite mesh-invite2-…

If no member is online yet, the node shows that it is waiting for network members.

4. Open a device by its name

On the device with the web interface, open the network's Shared services (ports) tab and publish the port, shared with all members or selected ones. Only programs running on that device itself can be shared.

Each device has a name: two random words by default, such as finch-unwary. The Ports shared with you tab shows the exact link. To use a short name such as nas, set node.name in the settings file.

On your computer, set the browser to use the node's proxy: address 127.0.0.1, port 1080 (it speaks HTTP and SOCKS5). Then type the address with http://, for example http://nas.meshtown. The Ports shared with you tab shows each link.

For SSH, RDP and other programs, use Open on this computer: a member's port gets a local port, for example 22 becomes 127.0.0.1:2022.

Update and remove

Update:

brew upgrade meshtown

Remove:

brew uninstall meshtown

Troubleshooting

Homebrew refuses the formula after brew tap
Newer Homebrew versions do not trust a new tap until you run:
brew trust mesh-town/meshtown
"MeshTown" cannot be opened
See the Gatekeeper note above: Open Anyway, or remove the quarantine mark.
Where are the settings and logs?
~/Library/Application Support/meshtown/ holds config.json and the logs meshtown.log and meshtown-tray.log. Keep config.json private.
