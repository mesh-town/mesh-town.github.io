Install Mesh Town on Android

For 64-bit ARM phones with Android 7.0 or newer. The app is installed from a file.

  • macOS
  • Windows
  • Linux
  • Android
  • OpenWrt
  • Keenetic

1. Install

  1. On the phone, download meshtown.apk.
  2. Open the file. Android asks to allow installing apps from this source: allow it.
  3. Start Mesh Town.

2. Make sure it works

The app opens and shows the Members and Device settings tabs.

3. Join your network

Ask a member of your network to press Invite a member on their node page and give you the single-use string. Open Mesh Town on the phone and join with it.

What the phone can do

The phone is a member of the network like any other device. For details, see the usage reference.

Update

Download the file again from the same link and install it over the old one.

Troubleshooting

Android does not offer to install the file
Allow installing unknown apps for the browser or file manager you opened it from.
The app does not install
It needs a 64-bit ARM phone and Android 7.0 or newer.
No connection on mobile data
Some mobile operators prevent direct connections between nodes; try Wi-Fi.
