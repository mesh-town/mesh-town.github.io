Install Mesh Town on Linux

For 64-bit x86 and ARM. Debian and Ubuntu get an apt package; other distributions use a static build.

  • macOS
  • Windows
  • Linux
  • Android
  • OpenWrt
  • Keenetic

1. Install

Debian and Ubuntu (apt)

x86_64:

wget https://mesh-town.github.io/meshtown-dist/linux/debian/meshtown_amd64.deb
sudo apt install ./meshtown_amd64.deb

ARM64:

wget https://mesh-town.github.io/meshtown-dist/linux/debian/meshtown_arm64.deb
sudo apt install ./meshtown_arm64.deb

The package adds a signed apt repository, so later updates come with apt. It also installs a meshtown service, stopped. On a server, start it:

sudo systemctl enable --now meshtown

The service reads /etc/meshtown/config.json. On a desktop with the tray app, leave the service off.

Any distribution (static build)

Tray app: meshtown-linux-x86_64.tar.gz · meshtown-linux-aarch64.tar.gz

Console only: meshtown-cli-linux-x86_64.tar.gz · meshtown-cli-linux-aarch64.tar.gz

curl -LO https://github.com/mesh-town/meshtown-dist/raw/main/linux/meshtown-linux-x86_64.tar.gz
tar -xzf meshtown-linux-x86_64.tar.gz

Run meshtown for the tray app, or meshtown-cli in a terminal or on a server.

2. Make sure it works

The node page opens from the tray icon, or with the sign-in link printed at start:

Mesh Town page: http://127.0.0.1:7777/?token=…

On the first visit, the page asks you to set a password. The sign-in link works once and for 10 minutes; after that, sign in with that password.

3. Create or join a network

On the node page, press Create a new network and give it a name, for example home-lab. You become its first administrator; making a second administrator soon is a good idea.

To add a device or a person, press Invite a member. You get a single-use string, valid for a day, that does not contain the network key. Hand it over in person. The node page shows the invite as a link and a QR code; on Android, the Scan QR button reads it.

On the new device, press Join with an invite and paste the string. In a terminal:

meshtown run --invite mesh-invite2-…

If no member is online yet, the node shows that it is waiting for network members.

4. Open a device by its name

On the device with the web interface, open the network's Shared services (ports) tab and publish the port, shared with all members or selected ones. Only programs running on that device itself can be shared.

Each device has a name: two random words by default, such as finch-unwary. The Ports shared with you tab shows the exact link. To use a short name such as nas, set node.name in the settings file.

On your computer, set the browser to use the node's proxy: address 127.0.0.1, port 1080 (it speaks HTTP and SOCKS5). Then type the address with http://, for example http://nas.meshtown. The Ports shared with you tab shows each link. While the proxy is set, the browser reaches every site through the node, so keep Mesh Town running; if you stop it, remove the proxy.

For SSH, RDP and other programs, use Open on this computer: a member's port gets a local port, for example 22 becomes 127.0.0.1:2022.

Update and remove

Update:

sudo apt update && sudo apt upgrade

For a static build, download the archive again.

Remove:

sudo apt remove meshtown

Troubleshooting

The service does not start by itself
It is installed stopped on purpose:
sudo systemctl enable --now meshtown
Where is the settings file?
/etc/meshtown/config.json for the service, ~/.config/meshtown/config.json for a user. Keep it private; meshtown config-path prints the one in use.
The other devices never appear
One of the networks may prevent direct connections; try another network.
