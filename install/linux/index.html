Install Mesh Town on Linux

Three steps: the package, the node page and your network. After that, shared devices open by name.

64-bit x86 and ARM.

  • macOS
  • Windows
  • Linux
  • Android
  • OpenWrt
  • Keenetic

  1. Install

    Debian / Ubuntu

    A=$(dpkg --print-architecture)
wget https://mesh-town.github.io/meshtown-dist/linux/debian/meshtown_${A}.deb
sudo apt install ./meshtown_${A}.deb

    The package adds a signed apt repository, so later updates come with apt, and installs the meshtown service, stopped. On a desktop, run meshtown for the tray app and leave the service off.

    On a server, join your network first with an invite from a member (step 3):

    sudo meshtown run --config /etc/meshtown/config.json --invite mesh-invite2-…

    Stop it with Ctrl+C once it reports joining, then start the service:

    sudo systemctl enable --now meshtown

    Other Linux

    curl -LO https://github.com/mesh-town/meshtown-dist/raw/main/linux/meshtown-linux-$(uname -m).tar.gz
tar -xzf meshtown-linux-$(uname -m).tar.gz

    Run meshtown for the tray app, or meshtown-cli in a terminal or on a server. For the console-only archive, use meshtown-cli-linux-$(uname -m).tar.gz in the same place.

  2. Open the node page

    Start meshtown for the tray app, or meshtown-cli in a terminal. The node page opens from the tray icon, or from the sign-in link printed at start (a service writes it to the system log):

    Mesh Town page: http://127.0.0.1:7777/?token=…

    The link works once and for 10 minutes. On the first visit, set a password; after that, sign in with it.

  3. Create or join a network

    Press Create a new network and name it, for example home-lab. You become its first administrator; add a second one soon.

    To add a device or a person, press Invite a member: you get a single-use string, valid for a day, that does not contain the network key. Hand it over in person. The page also shows it as a link and a QR code; on Android, Scan QR reads it.

    On the new device, press Join with an invite and paste the string, or in a terminal:

    meshtown run --invite mesh-invite2-…

    Until a member is online, the node reports that it is waiting for network members.

Open a device by its name

On the device that runs the service, open the network's Shared services (ports) tab and publish the port, to all members or to selected ones. Only programs running on that device itself can be shared.

Each device has a name, two random words by default, such as finch-unwary; for a short one such as nas, set node.name in the settings file. The Ports shared with you tab shows the exact link for every port.

In the browser: in your system's proxy settings, turn on automatic proxy configuration (PAC) and paste http://127.0.0.1:1080/proxy.pac. Then type the address with http://, for example http://nas.meshtown. Ordinary sites go through the node while Mesh Town runs and open directly while it is stopped; *.meshtown addresses work only through the node.

For SSH, RDP and other programs, press Open on this computer: a member's port gets a local port, for example 22 becomes 127.0.0.1:2022.

Update and remove

Debian / Ubuntu

Update

sudo apt update && sudo apt upgrade

Remove

sudo apt remove meshtown

Other Linux

Update: download the archive again and unpack it over the old files.

Remove: delete the unpacked files.

Troubleshooting

The service does not start by itself

It is installed stopped on purpose:
sudo systemctl enable --now meshtown

Where is the settings file?

/etc/meshtown/config.json for the service, ~/.config/meshtown/config.json for a user. Keep it private; meshtown config-path prints the one in use.

The other devices never appear

One of the networks may prevent direct connections; try another network.
