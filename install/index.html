Install Mesh Town

Pick your system.

  • macOSApple silicon and Intel
  • Windows64-bit x86
  • LinuxDebian, Ubuntu and other distributions
  • Androidapp from a file, Android 7.0 or newer
  • OpenWrtrouters on 24.10 and 25.12
  • Keeneticrouters with Entware (experimental)

Mesh Town does not run on iPhone or iPad.

Checksums and all release files are in the downloads repository; files without a version in the name are always the latest build.
