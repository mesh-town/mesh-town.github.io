Install Mesh Town

Pick your system. Each guide covers the install, the node page and joining your network.

  • macOSMenu bar app · Apple silicon and Intel
  • WindowsTray app · 64-bit x86
  • LinuxTray app or service · x86 and ARM
  • AndroidApp from a file · Android 7.0 or newer
  • OpenWrtService on the router · OpenWrt 24.10 and 25.12
  • KeeneticService on the router · Entware, experimental

There is no app for iPhone or iPad; they can use Mesh Town on a router: see connecting devices.

Checksums and all release files are in the downloads repository; files without a version in the name are always the latest build.
